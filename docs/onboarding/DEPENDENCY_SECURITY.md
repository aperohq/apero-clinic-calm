No new application dependency names, paid services or accounts were added. Package changes are limited to these versions and removal of duplicate already-patched Zod copies. Existing optional Nitro/ocache peer-resolution warnings remain; the lock diff does not change those packages. Vite/editor applicability depends on development configuration and operating system; the audit result is not a claim that every finding was exploitable in deployed Apero.

The patched dependency graph passed application/Edge TypeScript checks, production build, portable SQL/UI scope runner, real Chromium responsive acceptance and integrated browser/Supabase-SDK/native PostgreSQL rehearsal. The native SQL schema/concurrency suite also passes independently. Before/after audit JSON and final logs are in `validation-evidence/`.

The original checkout contains preexisting dependency-version differences from upstream main. The isolated branch and its installed lockfile are the authoritative tested release candidate; do not conflate its evidence with arbitrary unmerged working-copy changes. Production publication and deployment approval remain separate.

Privileged readiness/intake helpers also pin `pg_temp` after `pg_catalog` and `public`, so a caller's temporary relation cannot shadow the real security catalog. A regression creates a temporary `pg_class` lookalike while real client RLS is disabled and verifies readiness still fails. Approval/data fingerprints use built-in SHA-256; a digest-shape and stale-data regression cover this contract. These changes are local proposals, not production modifications.
